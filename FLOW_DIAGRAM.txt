╔══════════════════════════════════════════════════════════════════════════════╗
║                             SECURITY FEATURES                                ║
╚══════════════════════════════════════════════════════════════════════════════╝

✅ Passwords: bcrypt with cost=12 (never stored in plain text)
✅ OTP Generation: secrets.randbelow() (cryptographically secure)
✅ OTP Comparison: secrets.compare_digest() (constant-time, prevents timing attacks)
✅ OTP Expiry: 10 minutes (configurable)
✅ OTP Reuse Prevention: is_used flag, marked true after verification
✅ Email Enumeration Prevention: /forgot-password always returns 200
✅ Input Validation: Email, phone, password strength checked on backend
✅ HTTPS Ready: CORS configured, can switch to HTTPS in production
✅ JWT Tokens: HS256, 24-hour expiry (configurable)
✅ Row-Level Security: Supabase RLS enabled, backend uses service-role key
