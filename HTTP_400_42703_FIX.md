# ✅ HTTP 400 ERROR FIX - Code 42703 (Undefined Column)

## Error You're Seeing
```
Error: HTTP 400 | {"code":"42703", "details":null, "hint":"Perhaps you meant to r..."}
```

## What This Means
**PostgreSQL Error 42703 = "undefined column"**

The query is trying to filter on `provider_id` column, but your database table uses `firebase_uid` instead.

I've fixed the code to use `firebase_uid` instead of `provider_id`:

## 🔍 WHY THIS HAPPENED

1. Your existing tables use `firebase_uid` (matching the `users` table pattern)
2. The previous SQL I provided used `provider_id`
3. When you ran the SQL with `IF NOT EXISTS`, it didn't recreate the tables
4. Code was querying wrong column name → HTTP 400 error
