TROUBLESHOOTING

If "Cannot resolve symbol" errors:
→ Edit → Select All (Ctrl+A)
→ Code → Optimize Imports (Ctrl+Alt+O)
→ Rebuild

If "No resource found" XML errors:
→ Verify XML file exists in layout folder
→ Check file name matches (case-sensitive)
→ Rebuild Android Studio

If admin login fails immediately:
→ Check Supabase SUPABASE_URL in code
→ Check ANON_KEY is correct
→ Verify Firebase credentials

If "User is not an admin" after login:
→ Check you inserted user into admin_users
→ Verify admin_role_id exists in admin_roles
→ Check firebase_uid is exactly correct

If app crashes on admin activities:
→ Check all XML layouts are copied
→ Verify AndroidManifest has all activities
→ Check R class is up-to-date (rebuild)
